1. Desktop (Head) Mode Description
(For the Mercury-The-Headless-Zombie-Media-Stack repository)
> A "set-and-forget" Linux Media Server stack optimized for older hardware (Zorin/Ubuntu), NVIDIA GPUs (GTX 750), and full smartphone control. This version is designed for users who want to maintain a functional Desktop GUI for local tasks while running a powerful automated media empire in the background. It includes a unique "Zombie" persistence logic to ensure your services stay alive and accessible.
> 
2. Full Headless Zombie Edition Description
(For the -MERCURY-THE-FULL-HEADLESS-ZOMBIE-EDITION-v1.2- repository)
> The official blueprint for a dedicated, monitor-free media server. This edition "Beheads" the system by disabling the Desktop GUI to reclaim 1–2GB of RAM and significant CPU power, allowing your hardware to focus entirely on high-performance media transcoding. Designed for dedicated server builds, it transforms any PC into a silent, headless powerhouse controlled entirely via your smartphone.
> 
Key Differences at a Glance
| Feature | Desktop (Head) Mode | Headless Zombie Edition |
|---|---|---|
| Primary Goal | Local use + Media Server | Maximum performance for dedicated server |
| Visuals | Boots to Desktop GUI | Boots to Terminal (Beheaded) |
| RAM Efficiency | Standard | Optimized (Reclaims ~2GB RAM) |
| Control | Monitor or Smartphone | Smartphone is the Crown |
